# [TQ-C3-01] Persister TripQuest dans PostgreSQL avec un modèle relationnel contraint

- Roadmap Cycle: 3
- Roadmap Position: S13 (position 1 du cycle 3)
- Primary Roadmap Topic: S13 Modélisation PostgreSQL (modèle relationnel, contraintes, normalisation, types, ownership)
- Secondary Roadmap Topics: S1/S2 (invariants du noyau) ; S17 Migrations (schéma sous contrôle de version dès le départ) ; S12 Sécurité (ownership des données)
- Functional Capability: durabilité de l'ensemble des capacités du MVP
- Nature: DATA
- Maturity: `OUTLINE`
- Dependencies: TQ-C2-06
- Context Summary: TripQuest fonctionne en mémoire (ou avec un support transactionnel minimal issu de TQ-C2-06). Un redémarrage perd les voyages, invitations, propositions, votes et itinéraires.
- Problem Summary: Aucune durabilité ; les invariants d'unicité (email unique, un vote par participant et par activité, une seule invitation active par email et par voyage, une activité au plus une fois dans l'itinéraire) ne sont garantis que par le code, donc pas contre une seconde instance ni contre une erreur de programmation.
- Objective: Schéma relationnel PostgreSQL exprimant les entités et relations du MVP, avec contraintes d'unicité, d'intégrité référentielle et de domaine, types adaptés (dates avec fuseau, montants exacts, états), et ownership des données identifiable.
- Expected Outcome: Un voyage survit au redémarrage ; toute violation d'un invariant d'unicité est refusée par la base, pas seulement par le code ; le schéma est versionné et créé de façon reproductible.
- Expected Evidence: Schéma sous contrôle de version ; tests de violation de contraintes ; note de modélisation (normalisation, types, décisions).
- Topics Explicitly Deferred: Accès via JPA (TQ-C3-02), verrouillage (TQ-C3-03), index de performance (TQ-C3-04), évolution expand/contract (TQ-C3-05).
- Unknowns: `UNKNOWN` identifiants (UUID vs séquence) ; `UNKNOWN` représentation des états (enum, check, table) ; `UNKNOWN` schéma unique ou un schéma par module ; `UNKNOWN` représentation du temps (instant + fuseau du voyage vs heure locale).
