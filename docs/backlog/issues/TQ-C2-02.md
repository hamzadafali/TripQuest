# [TQ-C2-02] Démarrer et configurer TripQuest de manière reproductible (profils, propriétés, santé)

- Roadmap Cycle: 2
- Roadmap Position: S8 (position 2 du cycle 2)
- Primary Roadmap Topic: S8 Spring Boot internals (auto-configuration, conditional beans, starters, configuration properties, Actuator)
- Secondary Roadmap Topics: S6 Virtual Threads (décision d'exécution du serveur) ; S27 CI/CD ; S28 Kubernetes (probes futures)
- Functional Capability: transversale — paramètres produit (délai d'expiration des invitations, tailles maximales de groupe), santé de l'application
- Nature: OPERATIONS
- Maturity: `OUTLINE`
- Dependencies: TQ-C2-01
- Context Summary: TripQuest est assemblé dans Spring mais ses paramètres (expiration des invitations MEMBER-02, limites de groupe, paramètres du harnais) sont codés en dur, et le démarrage repose sur des auto-configurations non examinées.
- Problem Summary: Impossible de faire varier un paramètre produit sans recompiler ; un paramètre invalide n'est détecté qu'à l'usage ; on ignore quelles auto-configurations sont actives et pourquoi ; aucune information de santé n'est exposée.
- Objective: Configuration typée et validée au démarrage, profils local et test, rapport d'auto-configuration compris, beans conditionnels préparant la coexistence adaptateurs en mémoire / persistance future, santé exposée.
- Expected Outcome: Un paramètre invalide fait échouer le démarrage avec un message exploitable ; l'état de santé est consultable ; la décision sur l'exécution du serveur en threads virtuels est prise et tracée.
- Expected Evidence: Test de validation des propriétés ; rapport d'auto-configuration annoté ; endpoint de santé ; ADR threads virtuels côté serveur en cohérence avec TQ-C1-02.
- Topics Explicitly Deferred: Métriques et traces (TQ-C5-02), conteneurisation (TQ-C5-03).
- Unknowns: `UNKNOWN` liste des paramètres produit réellement nécessaires ; `UNKNOWN` activation des threads virtuels côté serveur (dépend du pinning constaté en TQ-C1-02) ; `UNKNOWN` exposition ou non d'informations de build.
