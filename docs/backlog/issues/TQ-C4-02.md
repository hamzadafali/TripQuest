# [TQ-C4-02] Borner les appels sortants de TripQuest : timeouts, retries, circuit breaker (enabler à valider)

- Roadmap Cycle: 4
- Roadmap Position: S20 (position 2 du cycle 4)
- Primary Roadmap Topic: S20 Clients HTTP résilients (timeouts, connection pools, retries, backoff, circuit breaker, bulkhead)
- Secondary Roadmap Topics: S11 Authentication (fournisseur d'identité) ; S25 Tests (pannes simulées) ; S26 Observabilité
- Functional Capability: `UNKNOWN / TO VALIDATE` — candidat vérifiable : appels au fournisseur OIDC (découverte, clés de signature) introduits par TQ-C2-04 ; l'envoi d'emails est hors MVP
- Nature: TECHNICAL ENABLER
- Maturity: `OUTLINE`
- Dependencies: TQ-C2-04
- Context Summary: Le MVP ne consomme aucun service externe métier. Le seul appel sortant probable est celui du resource server vers le fournisseur d'identité. Le lien externe d'une activité ne doit jamais être appelé (SSRF, TQ-C2-05).
- Problem Summary: `UNKNOWN / TO VALIDATE`. Si des appels sortants existent, un fournisseur lent ou en panne peut bloquer les threads de TripQuest sans limite de temps, épuiser le pool de connexions et rendre l'application indisponible pour tous les voyages.
- Objective: Au début du ticket, inventorier les appels sortants réels. S'il en existe, définir tous leurs timeouts, la politique de réessai avec backoff, le circuit breaker et le cloisonnement, puis démontrer le comportement sous pannes simulées. Sinon, remplacer par un ticket technique équivalent sur décision humaine.
- Expected Outcome: Si validé : aucun appel sortant sans timeout ; une panne du fournisseur dégrade TripQuest de façon bornée et observable. Ce n'est pas une décision architecturale approuvée.
- Expected Evidence: Inventaire des appels sortants ; configuration des timeouts ; tests de pannes simulées ; observation du circuit breaker ; ou décision humaine documentée.
- Topics Explicitly Deferred: Messagerie (TQ-C4-03).
- Unknowns: `UNKNOWN / TO VALIDATE` appels sortants réels ; `UNKNOWN` bibliothèque de résilience ; `UNKNOWN` comportement attendu de TripQuest quand le fournisseur d'identité est indisponible.
