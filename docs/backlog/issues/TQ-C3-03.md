# [TQ-C3-03] Garantir la cohérence des votes et décisions concurrentes au niveau de la base

- Roadmap Cycle: 3
- Roadmap Position: S16 (position 3 du cycle 3 dans ce backlog ; placé avant S15)
- Primary Roadmap Topic: S16 Transactions et concurrence (MVCC, isolation, lost update, deadlocks, optimistic/pessimistic locking)
- Secondary Roadmap Topics: S5 Concurrence Java (garanties de TQ-C1-02 reportées) ; S10 Transactions Spring ; S14 Locking JPA
- Functional Capability: Votes (VOTE-08, AC-5), Participants (MEMBER-03, MEMBER-06), décisions de l'organisateur
- Nature: RELIABILITY
- Maturity: `OUTLINE`
- Dependencies: TQ-C3-02
- Context Summary: Les garanties de concurrence établies en mémoire (TQ-C1-02) ne protègent plus rien dès que la base est la source de vérité et que plusieurs instances ou transactions agissent.
- Problem Summary: Lost update sur l'état du voyage ou sur une proposition entre deux transactions ; doublons évités uniquement par contrainte sans réponse métier claire ; interblocages possibles entre décisions touchant les mêmes lignes dans des ordres différents ; niveau d'isolation choisi par défaut sans analyse.
- Objective: Reproduire les anomalies concurrentes en base, puis les résoudre par une stratégie explicite (contraintes, verrouillage optimiste ou pessimiste, niveau d'isolation) adaptée à chaque opération ; documenter pourquoi.
- Expected Outcome: Les critères de TQ-C1-02 restent vrais avec PostgreSQL comme source de vérité et plusieurs transactions simultanées ; un conflit produit un refus exploitable, jamais une perte silencieuse.
- Expected Evidence: Anomalie reproduite sous le niveau d'isolation par défaut ; deadlock reproduit et résolu ; tests concurrents sur la base ; ADR de stratégie de verrouillage.
- Topics Explicitly Deferred: Cohérence entre base et messagerie (TQ-C4-06) ; idempotence côté API (TQ-C4-01).
- Unknowns: `UNKNOWN` devenir du mécanisme en mémoire de TQ-C1-02 ; `UNKNOWN` verrouillage optimiste par version ou pessimiste par opération ; `UNKNOWN` niveau d'isolation retenu par opération.
